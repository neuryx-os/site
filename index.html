Seu servidor de IA local, pronto desde o primeiro boot.

O Neuryx é uma edição do Lyra OS Server preparada para rodar modelos de linguagem na sua própria máquina, com llama.cpp integrado e configuração de GPU guiada.

Acompanhar o projeto Ler as decisões técnicas

Por que Neuryx

Montar um servidor de inferência do zero ainda exige driver, CUDA, compilação e serviço configurados à mão. O Neuryx entrega isso integrado.

Pronto para usar

llama.cpp empacotado, serviço configurado e API compatível com OpenAI. Você aponta para um modelo e começa.

Seus dados ficam com você

Os modelos rodam no seu hardware. Nenhum prompt precisa sair da sua rede, o que simplifica privacidade e conformidade com a LGPD.

Base estável do Lyra

Construído sobre o Lyra OS Server. Cada correção da base chega ao Neuryx, e o Vega cuida da administração do sistema.

Como funciona

  1. 01

    Instale a imagem

    ISO para servidores físicos, ou imagem qcow2 e de nuvem para máquinas virtuais.

  2. 02

    Configure a GPU

    No primeiro boot, o Neuryx detecta a placa e instala o driver a partir do repositório oficial do fabricante.

  3. 03

    Sirva um modelo

    Baixe um modelo GGUF e publique-o como serviço. Suas aplicações conversam com ele pela API compatível com OpenAI.

Uma camada de IA sobre uma base que já existe

O Neuryx não reinventa o sistema. Ele usa os pacotes do Lyra OS Server e acrescenta só o necessário para inferência: o runtime, os ajustes de sistema e a ferramenta de gestão.
